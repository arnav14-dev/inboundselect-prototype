# Inbound Select prototype

An interactive prototype of Inbound Select: the marketing site plus the product that agencies and agents use.

**Live:** https://arnav14-dev.github.io/inboundselect-prototype/

- Start on the home page, or go straight to the product with **Sign in**.
- Everything runs in the browser. Product screens use sample data, and the forms don't send anything.
- Plain HTML, CSS and JavaScript, with no build step.
